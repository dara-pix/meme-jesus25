Почти год назад прикола ради очень твердо решила написать микро-игру по мему с иисусом, а сейчас очень твердо решила ее выложить. Немного довела до ума и, собственно, вот.

Возможности: при наведении на кнопку "МОЧА" 3D Иисус вытягивает руку с бокалом и произносит "моча", а при наведении на "ХЛЭБ" - вытягивает руку с хлебом и говорит "хлэб". Можно поставить на фон одну из предложенных песен, изменить громкость или выключить звук.
